# 疑難排解

## 找不到另一台裝置

- 兩台裝置在同一個子網路內。探索不會跨越路由器。
- 防火牆允許 UDP 45457。
- 兩台裝置都啟用了同步。
- 如果廣播被阻擋，請在 **配對裝置 → 輸入位址** 中直接填寫位址。

## 配對失敗或配對碼不同

- 兩台裝置版本相同，而且都在執行。
- 接收方已開放 TCP 45456。
- 配對碼由握手推導而來，不一致代表握手沒有完成。請拒絕後重試。
- 金鑰發生變化的裝置必須重新配對；舊的記錄已不吻合。

## 項目一直停留在等待中或失敗

- 對方離線或無法連線。請檢查位址和防火牆。
- 傳送會自動重試，再次配對也會把目前看板補發過去。
- **失敗** 只表示上一次嘗試；之後的重試仍可能成功。

## 沒有傳送任何內容

- **設定 → 同步 → 啟用同步** 已開啟。
- 針對所複製的內容，**文字與連結**、**圖片** 或 **檔案與資料夾** 已開啟。
- 項目沒有超過 **圖片大小上限** 或 **檔案大小上限**。

## 圖片或檔案沒有同步

- 圖片以 PNG 傳送。檔案與資料夾會遞迴複製，並依 SHA-256 儲存。
- 超過 **設定 → 同步 → 檔案大小上限**（預設 512 MB）或超過 1,000 個項目的選擇會被略過。
- 如果傳輸一直停在 **失敗**，請查看日誌；未完成的 blob 會保留，下次嘗試會從斷點繼續。

## 歷史比預期短

- **設定 → 歷史 → 保留項目數** 限制了本機歷史。
- 曾經離線的裝置會在重新連線後補齊缺少的項目，請稍等片刻。

## 日誌

開啟 **設定 → 關於 → 開啟日誌**。資料夾中包含目前日誌和更早的日誌。
