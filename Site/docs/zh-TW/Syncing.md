# 同步

## 共享的內容

| 剪貼簿內容 | 狀態 |
| --- | --- |
| 文字 | 共享 |
| URL | 以文字共享 |
| 圖片 | 以 PNG 共享 |
| 檔案 | 尚未支援 |

在檔案管理員複製的檔案目前會被忽略。圖片受設定中的 **圖片大小上限** 限制（1–32 MB，預設 10 MB）；超過上限的圖片會被跳過，也不會進入歷史。

## 看板

**裝置** 頁面就是共享看板。每台裝置連同它產生的項目一起顯示，包括這台裝置自己。每個項目都有傳輸狀態：

| 狀態 | 含義 |
| --- | --- |
| 已同步 | 所有已配對裝置都確認收到該項目。 |
| 傳送中 | 這台裝置仍在傳送。 |
| 接收中 | 項目正從另一台裝置傳來。 |
| 等待中 | 對方離線，稍後會重試。 |
| 失敗 | 上一次嘗試沒有完成。 |

項目下方會顯示持有該項目的裝置數量：`4 台裝置中有 3 台擁有此項目。`

## 複製時的流程

1. 剪貼簿監視器儲存項目，並把這台裝置記為來源。
2. 透過加密工作階段傳送給所有已配對裝置。
3. 每台裝置儲存項目、套用到自己的剪貼簿，並轉發給仍需要的裝置。
4. 定期核對會重送尚未被確認的項目。

監視器會忽略 ClipboardSync 自己造成的剪貼簿變化，因此套用收到的項目不會又被送回去。

## 離線裝置

離線的裝置會保留自己的副本，並把尚未收到的項目顯示為 **等待中**。重新連線後，定期核對和配對後的補發會補上缺少的項目，不需要重新複製。

## 關閉同步

**設定 → 同步 → 啟用同步** 只會停止傳送和接收，配對關係仍會保留。可以透過 **文字與連結** 與 **圖片** 選擇共享的內容。
