# 安全性

## 身分

每次安裝都會產生一對長期 Ed25519 金鑰。公鑰就是裝置的身分。兩台裝置配對時，會各自記錄對方的公鑰，之後一直使用它。

私鑰保存在應用程式的設定資料夾中。能讀取該資料夾的人就能以這台裝置的身分行動，因此請保護好自己的使用者帳戶。

## 配對

配對握手會證明雙方確實擁有自己聲稱的金鑰。兩邊畫面上的短碼由同一段握手記錄推導而來，因此比對兩個短碼可以發現不一致或中間人。

短碼不是密碼，也永遠不會透過網路傳送。

## 工作階段

每次連線都會產生新的 X25519 臨時金鑰。共享密鑰經過 HKDF-SHA256 推導出工作階段金鑰，每個訊框都用 ChaCha20-Poly1305
加密。握手記錄作為關聯資料，把每個訊框綁定到該工作階段。

每次連線都會建立新工作階段；一個工作階段被破解不會暴露之前或之後的工作階段。

## 受保護的範圍

- 剪貼簿項目（文字、URL、圖片、檔案與資料夾）在傳輸過程中都是加密的。檔案在組幀前會切分為 blob 範圍。
- 配對證明和工作階段訊框都經過認證，因此竄改會被發現。

每台裝置的 blob 儲存在本機磁碟上是明文。加密保護的是傳輸，而不是本機副本；如果內容敏感，請保護使用者帳戶和資料夾。

探索過程不是秘密：UDP 廣播會帶上裝置名稱、ID 和連接埠，方便其他裝置找到它。網路可以看到兩個位址在通訊以及資料量，但看不到剪貼簿內容。

## 首次信任

配對就是建立信任的時刻。如果裝置的金鑰之後發生變化，記錄的公鑰將不再吻合，必須重新配對。每次都要比對配對碼；不要接受意料之外的請求。
