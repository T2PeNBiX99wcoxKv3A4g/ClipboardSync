# 配對

配對是讓兩台裝置互相信任的一次性步驟。它證明雙方確實擁有自己的金鑰，並記錄對方的公鑰。只有已記錄的裝置之間才會交換剪貼簿項目。

## 開始之前

- 兩台裝置都在執行 ClipboardSync，並且已開啟同步。
- 兩台裝置在同一個區域網路內，或能透過位址互相連線。
- 兩邊的防火牆都允許 TCP 45456。UDP 45457 只用於廣播線上狀態。

## 探索裝置

開啟 **裝置 → 配對裝置**。**探索到的裝置** 清單會在幾秒內從區域網路填入。選擇另一台裝置並按下 **配對**。

探索使用 UDP 廣播，無法跨越路由器。如果清單一直空白，請改用手動位址。

## 輸入位址

輸入另一台裝置的主機名稱或 IP 位址。預設連接埠是 45456；如果改過連接埠，請加上 `:連接埠`。

```
192.168.1.20
fedora-desktop:45456
```

兩台裝置都可以透過位址發起配對。

## 比對配對碼

兩邊畫面會顯示由握手推導出的同一組短 **配對碼**。確認兩邊一致，然後在等待確認的裝置上按下 **接受**。配對碼不會當成密碼傳送，只用來確認中間沒有其他裝置。

如果配對碼不同，請按下 **拒絕** 後重試。不一致代表兩邊沒有完成同一次握手。

## 收到的請求

另一台裝置發起配對時，這台裝置會跳出請求並顯示相同的配對碼。比對後按下 **接受** 或 **拒絕**。

## 取消配對

開啟 **裝置**，找到該裝置並按下 **取消配對**。對方將不再收到新項目。已經在看板上的項目會保留，因為看板是本機歷史，不是共享帳戶。

之後再次配對會重新記錄金鑰，並把目前看板作為補發內容傳送過去。
