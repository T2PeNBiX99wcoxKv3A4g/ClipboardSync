# 配对

配对是让两台设备互相信任的一次性步骤。它证明双方确实拥有自己的密钥，并记录对方的公钥。只有已记录的设备之间才会交换剪贴板项目。

## 开始之前

- 两台设备都在运行 ClipboardSync，并且已开启同步。
- 两台设备在同一局域网内，或能通过地址互相连接。
- 两边的防火墙都允许 TCP 45456。UDP 45457 只用于广播在线状态。

## 发现设备

打开 **设备 → 配对设备**。 **发现的设备** 列表会在几秒内从局域网填充。选择另一台设备并点击 **配对**。

发现使用 UDP 广播，无法跨路由器。如果列表一直为空，请改用地址。

## 输入地址

输入另一台设备的主机名或 IP 地址。默认端口是 45456；如果改过端口，请加上 `:端口`。

```
192.168.1.20
fedora-desktop:45456
```

两台设备都可以通过地址发起配对。

## 比对配对码

两边屏幕会显示由握手中推导出的同一组短 **配对码**。确认两边一致，然后在等待确认的设备上点击 **接受**
。配对码不会作为密码发送，只用于确认中间没有其他设备。

如果配对码不同，请点击 **拒绝** 后重试。不一致意味着两边没有完成同一次握手。

## 收到的请求

另一台设备发起配对时，这台设备会弹出请求并显示相同的配对码。比对后点击 **接受** 或 **拒绝**。

## 取消配对

打开 **设备**，找到该设备并点击 **取消配对**。对方将不再收到新项目。已经在面板上的项目会保留，因为面板是本地历史，不是共享账户。

以后再次配对会重新记录密钥，并把当前面板作为补发内容发送过去。
