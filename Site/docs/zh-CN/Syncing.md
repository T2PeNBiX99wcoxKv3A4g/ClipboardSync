# 同步

## 共享的内容

| 剪贴板内容 | 状态 |
| --- | --- |
| 文本 | 共享 |
| URL | 作为文本共享 |
| 图片 | 以 PNG 共享 |
| 文件 | 尚未支持 |

在文件管理器中复制的文件目前会被忽略。图片受设置中的 **图片大小上限** 限制（1–32 MB，默认 10 MB）；超过上限的图片会被跳过，也不会进入历史。

## 面板

**设备** 页面就是共享面板。每台设备连同它产生的项目一起显示，包括这台设备自己。每个项目都有传输状态：

| 状态 | 含义 |
| --- | --- |
| 已同步 | 所有已配对设备都确认收到了该项目。 |
| 发送中 | 这台设备仍在发送。 |
| 接收中 | 项目正从另一台设备传来。 |
| 等待中 | 对方离线，稍后会重试。 |
| 失败 | 上一次尝试没有完成。 |

项目下方会显示持有该项目的设备数量：`4 台设备中有 3 台拥有此项目。`

## 复制时的流程

1. 剪贴板监视器保存项目，并把这台设备记为来源。
2. 通过加密会话发送给所有已配对设备。
3. 每台设备保存项目、应用到自己的剪贴板，并转发给仍需要的设备。
4. 定期核对会重发尚未被确认的项目。

监视器会忽略 ClipboardSync 自己造成的剪贴板变化，因此应用收到的项目不会又被发回去。

## 离线设备

离线的设备会保留自己的副本，并把尚未收到的项目显示为 **等待中**。重新连接后，定期核对和配对后的补发会填上缺少的项目，不需要重新复制。

## 关闭同步

**设置 → 同步 → 启用同步** 只会停止发送和接收，配对关系仍会保留。可以通过 **文本和链接** 与 **图片** 选择共享的内容。
