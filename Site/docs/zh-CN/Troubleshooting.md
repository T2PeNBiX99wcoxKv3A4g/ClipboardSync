# 故障排除

## 找不到另一台设备

- 两台设备在同一子网内。发现不会跨路由器。
- 防火墙允许 UDP 45457。
- 两台设备都启用了同步。
- 如果广播被阻挡，请在 **配对设备 → 输入地址** 中直接填写地址。

## 配对失败或配对码不同

- 两台设备版本相同，并且都在运行。
- 接收方已开放 TCP 45456。
- 配对码由握手推导而来，不一致说明握手没有完成。请拒绝后重试。
- 密钥发生变化的设备必须重新配对；旧的记录已不匹配。

## 项目一直停留在等待中或失败

- 对方离线或无法连接。请检查地址和防火墙。
- 发送会自动重试，再次配对也会把当前面板补发过去。
- **失败** 只表示上一次尝试；之后的重新尝试仍可能成功。

## 没有发送任何内容

- **设置 → 同步 → 启用同步** 已开启。
- 针对所复制的内容，**文本和链接**、**图片** 或 **文件和文件夹** 已开启。
- 项目没有超过 **图片大小上限** 或 **文件大小上限**。

## 图片或文件没有同步

- 图片以 PNG 发送。文件和文件夹会递归复制，并按 SHA-256 保存。
- 超过 **设置 → 同步 → 文件大小上限**（默认 512 MB）或超过 1,000 个条目的选择会被跳过。
- 如果传输一直停在 **失败**，请查看日志；未完成的 blob 会保留，下次尝试会从断点继续。

## 历史比预期短

- **设置 → 历史 → 保留项目数** 限制了本地历史。
- 曾经离线的设备会在重新连接后补齐缺少的项目，请稍等片刻。

## 日志

打开 **设置 → 关于 → 打开日志**。文件夹中包含当前日志和更早的日志。
