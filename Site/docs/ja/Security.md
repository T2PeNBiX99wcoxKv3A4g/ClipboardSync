# セキュリティ

## 識別情報

各インストールは長期的な Ed25519 鍵ペアを生成します。公開鍵が端末の識別子です。2 台がペアリングすると、互いの公開鍵を記録し、以後それを使います。

秘密鍵はアプリの設定フォルダに残ります。このフォルダを読める人はその端末として振る舞えるため、ユーザーアカウントを保護してください。

## ペアリング

ペアリングのハンドシェイクは、両方が主張する鍵を実際に持っていることを証明します。両方の画面に出る短いコードは同じやり取りから導出されるため、見比べることで不一致や途中の端末を発見できます。

コードはパスワードではなく、ネットワークに送られることもありません。

## セッション

接続ごとに新しい X25519 の一時鍵を生成します。共有秘密は HKDF-SHA256 を通してセッション鍵になり、すべてのフレームは ChaCha20-Poly1305 で暗号化されます。ハンドシェイクのやり取りは関連データとして使われ、各フレームをそのセッションに結び付けます。

接続ごとに新しいセッションを作るため、1 つのセッションが破られても前後のセッションは露出しません。

## 守られる範囲

- クリップボード項目（テキスト、URL、画像）は通信路上で暗号化されます。
- ペアリングの証明とセッションのフレームは認証されるため、改ざんは検出されます。

検出は秘密ではありません。UDP の通知には端末名、ID、ポートが含まれ、ほかの端末が見つけられるようになっています。ネットワークは 2 つのアドレスが通信していることと通信量は見えますが、クリップボードの中身は見えません。

## 初回の信頼

ペアリングが信頼の瞬間です。あとで端末の鍵が変わると記録した鍵と一致しなくなり、もう一度ペアリングが必要になります。毎回コードを見比べ、予期しないリクエストは承認しないでください。
