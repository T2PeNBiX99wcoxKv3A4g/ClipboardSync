# 同期

## 共有される内容

| クリップボードの内容 | 状態               |
|----------------------|--------------------|
| テキスト             | 共有               |
| URL                  | テキストとして共有 |
| 画像                 | PNG として共有     |
| ファイル             | 未対応             |

ファイルマネージャーでコピーしたファイルは今は無視されます。画像は設定の **画像サイズ上限**（1〜32 MB、既定 10
MB）で制限され、大きすぎる画像は履歴にも残りません。

## ボード

**デバイス** ページが共有ボードです。ペアリングしたすべての端末と、そこから届いた項目が表示されます。各項目には転送状態があります。

| 状態     | 意味                                 |
|----------|--------------------------------------|
| 同期済み | すべての相手が項目を確認しました。   |
| 送信中   | この端末がまだ送っています。         |
| 受信中   | ほかの端末から届いている途中です。   |
| 待機中   | 相手がオフラインで、再試行されます。 |
| 失敗     | 直前の試行が完了しませんでした。     |

項目の下の行には、その項目を持つ端末の数が表示されます: `4 台中 3 台がこの項目を持っています。`

## コピーしたときの流れ

1. クリップボード監視が、この端末をコピー元として項目を保存します。
2. 暗号化されたセッションで、ペアリングしたすべての端末に送ります。
3. 各端末は保存し、自分のクリップボードに反映し、まだ必要とする相手へ転送します。
4. 定期的な照合が、確認されていない項目を送り直します。

監視は ClipboardSync 自身が起こしたクリップボード変更を無視するので、受信した項目を反映しても送り返しません。

## オフラインの端末

オフラインの端末は自分のコピーを保持し、受け取っていない項目を **待機中**
と表示します。再接続すると、照合とペアリング後のまとめ送信が不足分を埋めます。コピーし直す必要はありません。

## 同期を止める

**設定 → 同期 → 同期を有効にする** をオフにすると、送受信は止まりますがペアリングは残ります。共有する内容は
**テキストとリンク** と **画像** で選べます。
