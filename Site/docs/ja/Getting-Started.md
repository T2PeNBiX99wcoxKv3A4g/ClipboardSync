# はじめに

ClipboardSync は、ペアリングした端末のクリップボードを同じ状態に保ちます。1
台でテキスト、リンク、画像をコピーすると、ほかの端末にも届きます。通信は端末同士が暗号化されたセッションで直接行います。

## 必要なもの

- Windows または Linux、x64。ビルドは自己完結型なので、.NET ランタイムをインストールする必要はありません。
- 互いに到達できる 2 台の端末。TCP 45456 がペアリングとクリップボードの通信に使われ、UDP 45457 はローカルネットワークの検出だけに使われます。
- Linux では WebKitGTK 4.1 と AppIndicator ライブラリ。AppIndicator がなくてもアプリは動作しますが、トレイアイコンが表示されません。

## 起動する

`ClipboardSync.exe`（または Linux のバイナリ）を起動します。ウィンドウを閉じてもトレイに残ります。同時に 1
つだけ動作し、もう一度起動すると既存のウィンドウが戻ります。

## 最初の端末をペアリングする

**デバイス → 端末をペアリング**
を開きます。検出された端末を選ぶかアドレスを入力し、両方の画面に出るコードを見比べます。[ペアリング](Pairing) を参照してください。

## 何かコピーする

任意のアプリでテキスト、URL、画像をコピーします。項目はこの端末の下に表示され、ペアリングした端末に送られ、そのクリップボードに反映されます。共有される内容とオフライン時の動作は [同期](Syncing)
を参照してください。

## データの保存場所

| 内容                               | Windows                        | Linux                          |
|------------------------------------|--------------------------------|--------------------------------|
| 設定、識別情報、ペアリング済み端末 | `%APPDATA%\ClipboardSync`      | `~/.config/ClipboardSync`      |
| 履歴と画像キャッシュ               | `%LOCALAPPDATA%\ClipboardSync` | `~/.local/share/ClipboardSync` |
| ログ                               | `%APPDATA%\ClipboardSync\logs` | `~/.config/ClipboardSync/logs` |

識別鍵はペアリング時に相手が記録するものです。このフォルダは自分のアカウントだけが読めるようにしてください。
