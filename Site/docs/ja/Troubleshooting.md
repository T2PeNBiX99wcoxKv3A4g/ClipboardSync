# トラブルシューティング

## 相手の端末が見つからない

- 2 台が同じサブネットにいます。検出はルーターを越えません。
- UDP 45457 がファイアウォールを通ります。
- 両方で同期が有効です。
- ブロードキャストが使えない場合は **端末をペアリング → アドレスを入力** で直接指定します。

## ペアリングに失敗する、コードが違う

- 2 台が同じバージョンで、どちらも起動しています。
- 受ける側で TCP 45456 が開いています。
- コードはハンドシェイクから作られるため、一致しないときはハンドシェイクが完了していません。拒否してやり直してください。
- 鍵が変わった端末はもう一度ペアリングが必要です。古い記録とは一致しません。

## 項目が待機中や失敗のまま

- 相手がオフラインか、到達できません。アドレスとファイアウォールを確認してください。
- 送信は自動で再試行され、もう一度ペアリングすると現在のボードをまとめて送ります。
- **失敗** は直前の試行の状態です。あとで再試行して成功することがあります。

## 何も送られない

- **設定 → 同期 → 同期を有効にする** がオンです。
- コピーした内容に応じて **テキストとリンク**、**画像**、**ファイルとフォルダー** がオンです。
- 項目が **画像サイズ上限** または **ファイルサイズ上限** 以下です。

## 画像やファイルが同期されない

- 画像は PNG として送られます。ファイルとフォルダーは再帰的にコピーされ、SHA-256 で保存されます。
- **設定 → 同期 → ファイルサイズ上限**（既定 512 MB）を超える選択や、1,000 エントリーを超える選択はスキップされます。
- 転送が **失敗** のままならログを確認してください。途中までの blob は保持され、次の試行で続きから再開します。

## 履歴が思ったより短い

- **設定 → 履歴 → 保持する項目数** がローカル履歴の上限です。
- オフラインだった端末は再接続後に不足分を埋めます。少し待ってください。

## ログ

**設定 → このアプリについて → ログを開く** を押します。フォルダには現在のログと過去のログがあります。
