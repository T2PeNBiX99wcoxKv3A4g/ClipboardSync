# ペアリング

ペアリングは、2 台の端末が互いを信頼するための一度だけの手順です。両方が鍵を持っていることを証明し、相手の公開鍵を記録します。クリップボード項目を交換するのは記録済みの端末だけです。

## 始める前に

- 両方の端末で ClipboardSync が動作していて、同期が有効です。
- 2 台が同じローカルネットワークにいるか、アドレスで到達できます。
- 両方で TCP 45456 がファイアウォールを通ります。UDP 45457 は存在を知らせるためだけに使われます。

## 端末を検出する

**デバイス → 端末をペアリング** を開きます。**検出された端末** の一覧は数秒で埋まります。相手を選んで **ペアリング** を押します。

検出は UDP ブロードキャストを使うため、ルーターを越えません。一覧が空のときはアドレスを入力してください。

## アドレスを入力する

相手のホスト名または IP アドレスを入力します。既定のポートは 45456 で、変更した場合は `:ポート` を付けます。

```
192.168.1.20
fedora-desktop:45456
```

アドレス入力はどちらの端末からでも開始できます。

## コードを見比べる

両方の画面に、ハンドシェイクから導出された同じ短い **ペアリングコード** が表示されます。一致することを確認し、確認待ちの端末で **承認** を押します。コードはパスワードとして送られることはなく、途中に別の端末がいないことを確かめるためだけに使います。

コードが違う場合は **拒否** してやり直してください。一致しないときは、両方で同じハンドシェイクが完了していません。

## 受信したリクエスト

相手がペアリングを開始すると、同じコードとともにリクエストが開きます。見比べて **承認** または **拒否** を押します。

## ペアリングを解除する

**デバイス** で相手を選び **ペアリング解除** を押します。相手は新しい項目を受け取らなくなります。すでにボードにある項目は残ります。ボードは共有アカウントではなく、ローカルの履歴だからです。

後でもう一度ペアリングすると、鍵を記録し直し、現在のボードをまとめて送ります。
